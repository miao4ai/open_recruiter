# openrecruiter-research-fairness

Bias and fairness research for candidate retrieval and ranking: datasets, bias evaluation,
anonymization, counterfactual testing, and fairness-aware ranking experiments.

This track is deliberately independent of the distillation work in `research/recruitgpt`,
so the two can support separate publications.

Specification pending.

**Status: scaffold.** No implementation yet — see the repo root [README](../../README.md) for where this sits in the plan.

## Install

```bash
pip install openrecruiter-research-fairness
```

## Build from source

```bash
cd research/fairness
uv build --out-dir dist   # -> dist/*.whl, dist/*.tar.gz
```
